# BMI Calculator

A simple and responsive BMI (Body Mass Index) Calculator built using HTML, CSS, and JavaScript. This project allows users to enter their height and weight, calculate their BMI, and view their health category instantly.

## 🚀 Features
- Calculate BMI using height and weight
- Displays BMI value with 2 decimal precision
- Shows health status:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Input validation for empty or invalid values
- Clear/reset functionality
- Clean and responsive UI design

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📌 How It Works
1. Enter your weight (kg)
2. Enter your height (meters)
3. Click "Calculate"
4. View your BMI score and category

## 🔄 Reset
- Click "Clear" to reset inputs and results

## 📷 UI Preview
Simple and modern interface with color-based result display.

## 📚 Formula Used
BMI = Weight (kg) / (Height (m) × Height (m))

## 🎯 Purpose
This project is created for learning basic web development and JavaScript DOM manipulation.
